## Scope

## Key Concepts (to be expanded)
- Topic clusters: pillar page (broad topic) + cluster pages (subtopics) + internal links
- Keyword cannibalization: multiple pages competing for the same query — detect and consolidate
- Content pruning: keep / update / merge / redirect / delete decision framework
- Content decay: pages losing traffic/rankings over time — identify and refresh
- Topical authority: how comprehensively a site covers its core topics
- Publishing cadence and content calendar planning
