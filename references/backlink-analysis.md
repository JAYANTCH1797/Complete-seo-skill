## Scope
Link profile audit, quality scoring, toxic link detection, competitor backlink analysis, link building strategy.

## Key Concepts (to be expanded)
- Five link quality dimensions: Authority, Relevance, Anchor text, Placement, Destination
- Backlink profile audit: referring domain count/quality, anchor text distribution, link velocity
- Toxic link detection: spammy domains, link schemes, PBN patterns
- Competitor backlink replication: find who links to competitors, identify replicable opportunities
- Link building strategies: Adding (directories), Asking (outreach), Earning (linkable assets), Buying (risky)
- Linkable asset creation: original research, tools, data studies, comprehensive guides
- Internal link equity: hub pages, orphan pages, link distribution to money pages
- Anchor text strategy: natural variation, avoid over-optimization

## Tools
- Semrush MCP: backlink_research (profile, referring domains, anchors)
- Domain Rating (DR), URL Rating (UR) as authority proxies
