# Content Gap Analysis Prompt

<!-- Reusable prompt for LLM-assisted content gap detection -->

## Instructions

Given the following inputs:
1. **Your page URL and content** (fetched)
2. **Top 3 competitor pages for the target keyword** (fetched)

Analyze and identify:

1. **Subtopic gaps**: What sections/topics do competitors cover that your page doesn't?
2. **Depth gaps**: Where do competitors go deeper on a topic you only mention briefly?
3. **Format gaps**: Do competitors use tables, lists, visuals, or tools that your page lacks?
4. **Freshness gaps**: Do competitors have more recent data, examples, or references?
5. **E-E-A-T gaps**: Do competitors show stronger expertise signals (author bios, citations, original data)?

Output a prioritized list of gaps with specific recommendations for each.
